# ring-relay invariants

Critical and High invariants of the `ring-relay` crate, taken from its source. Rust tests implement the claims. `services/ring-rpc/README.md` is the wire contract. Where the code and a document disagree, the code decides and the row names the divergence.

## Reading and maintaining the checklist

IDs are stable. Never renumber an invariant and never reuse a removed id. A new invariant takes the next free number of its area.

- `[x]` Covered: a named test asserts a result that fails when the invariant breaks.
- `[ ]` Partial: some assertions exist. The row names the missing case.
- `[ ]` Missing: no test asserts the claim. The row is test work.

Kinds: **auth** who may cause the operation, **pre** an acceptance or refusal condition, **post** the result on success, **rollback** the state after a refusal, **frame** what the operation leaves unchanged, **state** true at every observable moment, **wire** a byte layout or a label that a signature, a key or a stored row depends on.

Severity: **C** the service signs, pays or releases what it must not, or an authorization is bypassed. **H** a secret or a member's data leaks, a limit or a reservation miscounts, or the service accepts a corrupt stored row. Lower severities stay out of this file.

A source path that starts with `src/` is in this crate. Every other path starts at the repository root. A path names a file of this tree, and the symbol after it is the anchor. A test runs on SQLite unless its row says PostgreSQL. `just test-postgres` runs on PostgreSQL the ring-writer, ring-audit, ring-cosigner and ring-relay lib tests whose path holds `postgres` or `relay_reservations`, the ring-rpc `relay_service` tests, the ignored ring-rpc `audit_service` tests and the ignored ring-indexer lib tests. A concurrency claim that only SQLite covers is partial. A test under `program-tests/custom-ring/tests` runs only in the validator suite.

To change a row, read the source symbol and the test assertion, run the test, then set the mark. A test that only round-trips a derived serialization is no coverage.

A test marked "(no store)" opens no database.
